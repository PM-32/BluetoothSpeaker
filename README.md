# BluetoothSpeaker

(RU)
Краткое описание проекта:
Портативная Bluetooth-колонка, построенная на базе микроконтроллера ESP32.
Устройство предназначено для беспроводного воспроизведения звука
с устройств по протоколу Bluetooth A2DP. Имеется возможность управления
воспроизведением и переключением композиций, регулировка громкости,
управление Bluetooth соединением. Реализовано 6 различных пресетов
эквалайзера, влияющие на характер звучания колонки. Предусмотрена
индикация уровня заряда батареи и статуса Bluetooth-подключения.
Проект реализован в среде VS Code (плагин PlatformIO) с использованием
фреймворка Arduino.

Дополнительно.
Больше информации о проекте можно найти в файле "Description.pdf".

(EN)
Project Description:
A portable Bluetooth speaker based on the ESP32 microcontroller.
The device is designed for wireless audio playback from devices using
the Bluetooth A2DP protocol. It features playback and song switching
controls, volume adjustment, and Bluetooth connection management.
Six different equalizer presets are available, affecting the speaker's
sound. Battery level and Bluetooth connection status are also indicated.
The project is implemented in VS Code (PlatformIO plugin)
using the Arduino framework.

The project uses the following libraries:
1) arduino-audio-tools(https://github.com/pschatzmann/arduino-audio-tools)
2) ESP32-A2DP(https://github.com/pschatzmann/ESP32-A2DP)
3) Adafruit_NeoPixel(https://github.com/adafruit/adafruit_neopixel)
